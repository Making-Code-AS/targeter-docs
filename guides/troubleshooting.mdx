---
title: 'Troubleshooting'
description: 'Common problems and what to do about them'
---

<AccordionGroup>
  <Accordion title="I can't log in or see 'No access'">
    Log in with your email and the code we send you, or with a passkey. The code expires, and too many wrong tries require a new code. If you can sign in but see a no-access page, you do not have access to that app. Ask an admin to grant it under your user's app access.
  </Accordion>
  <Accordion title="No campaign plans appear when creating a campaign">
    Only active plans are listed. An admin must create a [budget tier and an active plan](/guides/campaign-plans) first.
  </Accordion>
  <Accordion title="The campaign has the status Error">
    Setup failed. Contact an administrator.
  </Accordion>
  <Accordion title="The campaign has the status Missing content">
    One or more ads have no images. Select images for every ad, then approve.
  </Accordion>
  <Accordion title="I can't approve the campaign">
    Check the requirements under [Review and approve](/guides/running-campaigns#review-and-approve). Common causes are a missing Facebook page on the office, a missing Google Ads Customer ID for web ads, or an ad without a platform strategy.
  </Accordion>
  <Accordion title="A Facebook page or Instagram account is missing">
    An office can be limited to selected pages and accounts. Ask an admin to check the office's allowed list, where an empty list means all are available.
  </Accordion>
  <Accordion title="I can't change the campaign dates">
    Pause the campaign first.
  </Accordion>
  <Accordion title="I can't delete an office or company">
    Delete is blocked while anything references it, such as users or campaigns.
  </Accordion>
  <Accordion title="My API secret is lost">
    Secrets are shown once. Delete the key and create a new one.
  </Accordion>
</AccordionGroup>
