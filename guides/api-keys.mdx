---
title: 'API keys'
description: 'How API credentials are issued for a company'
---

Each company can have one API key, created by a super admin under **Admin → API keys** in Targeter.

<Warning>
The secret is shown only once, when the key is created. Copy and store it securely. If it is lost, delete the key and create a new one.
</Warning>

Deleting a key removes the company's API access immediately.

Use the key and secret to [authenticate](/api-reference/endpoint/auth), then follow the [integration guide](/quickstart).
